**Изменения в 0.7.1**
- Рамка больше не встаёт по краю тени от телефона. Сторона, через которую продолжаются строки текста, не считается краем листа, а синеватая тень на странице не считается «посторонним фоном».
- Рамка не захватывает соседнюю страницу книги: если внутри рамки параллельно её стороне идёт корешок или край другого листа, выбирается рамка по нему. Напечатанные линии бланков и таблиц на это не влияют.

**Какой файл скачать**
- `app-arm64-v8a-release_0.7.1.apk` — для любого телефона примерно с 2017 года.
- `app-armeabi-v7a-release_0.7.1.apk` — только для очень старых 32-битных телефонов.

Ставится поверх предыдущей версии. Для уже снятых страниц нажмите «Авто» на экране границ листа.
