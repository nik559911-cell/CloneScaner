**Изменения в 0.7.2**
- На экране «Границы листа» в середине каждой стороны рамки появился продолговатый маркер. Потяните за него — сторона сдвинется целиком: оба её угла одновременно, параллельно самой себе. Лупа показывает середину стороны.

**Какой файл скачать**
- `app-arm64-v8a-release_0.7.2.apk` — для любого телефона примерно с 2017 года.
- `app-armeabi-v7a-release_0.7.2.apk` — только для очень старых 32-битных телефонов.
