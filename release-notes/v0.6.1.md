Офлайн-сканер документов: снимок или фото из галереи → обрезка по краям листа → белый фон без серости → PDF. Без интернета, аккаунта и рекламы.

**Какой файл скачать**
- `app-arm64-v8a-release_0.6.1.apk` — для любого телефона примерно с 2017 года.
- `app-armeabi-v7a-release_0.6.1.apk` — только для очень старых 32-битных телефонов.

Обновление ставится поверх версий начиная с 0.3.1 — сканы сохраняются.

**Что умеет**
- Съёмка камерой и импорт до 50 фото из галереи.
- Автоматический поиск листа, в том числе на пёстрой скатерти. Углы можно поправить вручную, при перетаскивании угла появляется лупа ×3 с крестиком.
- Выравнивание строк по горизонту (до ±15°) и поворот страницы на 90° кнопкой.
- Фильтры: «Белый фон», «Как есть», «Светлее», «Серый», «Ч/Б».
- Многостраничные документы: добавить страницу, переставить перетаскиванием, удалить, переименовать.
- «Сохранить» в «Загрузки/Сканер» и «Отправить» через любое приложение. PDF сжимается примерно на 40 % без заметной потери качества.

**Изменения в 0.6.1**
- Индикатор сборки PDF гаснет сразу после сохранения, а не после исчезновения сообщения.
