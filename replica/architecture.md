# Архитектура: «Сканер» (рабочее имя) — офлайн-сканер документов по образцу ядра CamScanner

Читает: `replica/recon.md`, `replica/features.csv`. Дата: 2026-10-23.

Это Android-приложение без сервера: нет аккаунтов, оплаты, почты и облака. Поэтому строки «auth / payments / email / hosting» из шаблона заменены тем, что здесь действительно нужно. Рабочее имя и пакет `app.skaner` поменяются на этапе brand.

## Стек

| слой | выбор | почему |
| --- | --- | --- |
| язык и UI | Kotlin + Jetpack Compose (Material 3), одна Activity, Navigation Compose | стандарт для нового Android-кода; экраны S01–S08 ложатся на Compose без XML |
| камера | CameraX: Preview + ImageCapture + ImageAnalysis | управляет жизненным циклом камеры; ImageAnalysis даёт кадры для живого контура листа (S02) |
| компьютерное зрение | OpenCV 4.14.0 из Maven Central (`org.opencv:opencv`), только `arm64-v8a` и `armeabi-v7a` | поиск краёв, коррекция перспективы и фильтры в одной офлайн-библиотеке; полный контроль над «белым фоном» — то, чего не даёт готовый сканер ML Kit |
| база | Room (SQLite) | документы и страницы — маленькая реляционная модель с порядком страниц |
| настройки | DataStore (Preferences) | 4 ключа из S08, база для них избыточна |
| файлы | внутреннее хранилище приложения `filesDir/docs/<doc>/` | приватно, без разрешений; оригинал хранится, чтобы переобрезать и менять фильтр (S06) |
| импорт фото | системный Photo Picker (`PickMultipleVisualMedia`) | без разрешения на хранилище; на старых Android подтягивается через Google Play services |
| PDF | собственный писатель PDF, страницы как JPEG (`DCTDecode`) | штатный `PdfDocument` раздувает файл, перекодируя картинки; свой писатель — около 150 строк и даёт размер ~200–400 КБ на страницу |
| поделиться | `FileProvider` + `ACTION_SEND` / `ACTION_SEND_MULTIPLE` | системное меню вместо облачных интеграций |
| сохранить в «Загрузки» | `MediaStore.Downloads` (API 29+), на API 26–28 — публичная папка с разрешением записи | без лишних разрешений на новых версиях |
| фоновые задачи | корутины, обработка на `Dispatchers.Default` | WorkManager не нужен: всё делается, пока приложение открыто |
| DI | вручную, через один `AppContainer` | маленькое приложение, Hilt не окупится |
| сборка | Gradle (Kotlin DSL) + version catalog; APK в GitHub Actions | у пользователя уже так собираются Android-проекты |
| версии Android | minSdk 26, targetSdk — текущий требуемый Google Play на момент сборки | 26 покрывает практически все рабочие телефоны |

Одна база, один модуль `:app`. Сетевых разрешений в манифесте нет вообще — офлайн гарантирован манифестом, а не обещанием.

## Схема

Таблиц: 3 (+ настройки в DataStore). Правил доступа нет: пользователь один, данные приватны для приложения.

```sql
-- Эквивалент Room-сущностей, см. также replica/schema.sql
create table folders (
  id          text primary key,              -- UUID
  name        text not null,
  created_at  integer not null               -- epoch millis, UTC
);

create table documents (
  id          text primary key,
  folder_id   text references folders(id) on delete set null,
  title       text not null,
  is_draft    integer not null default 1,    -- 1, пока идёт серия съёмки (F02)
  created_at  integer not null,
  updated_at  integer not null
);
create index idx_documents_folder  on documents(folder_id);
create index idx_documents_updated on documents(updated_at desc);

create table pages (
  id             text primary key,
  document_id    text not null references documents(id) on delete cascade,
  position       integer not null,           -- 0..n-1
  original_path  text not null,              -- снимок как есть (EXIF уже применён)
  processed_path text,                       -- null, пока не обработана
  thumb_path     text,
  quad           text,                       -- JSON: 4 точки [x,y] в координатах оригинала, null = весь кадр
  rotation       integer not null default 0 check (rotation in (0,90,180,270)),
  filter         text not null default 'white'
                 check (filter in ('original','white','lighten','gray','bw')),
  width          integer,
  height         integer,
  created_at     integer not null,
  updated_at     integer not null,
  unique (document_id, position)
);
create index idx_pages_document on pages(document_id, position);
```

Жёсткие ограничения: порядок страниц уникален внутри документа (SQLite не умеет откладывать проверку уникальности, поэтому перестановка — одна транзакция: сдвинуть затронутые позиции во временный отрицательный диапазон, затем записать новые); удаление документа каскадом удаляет страницы, а файлы удаляются после успешной транзакции.

Настройки (DataStore): `name_template` (по умолчанию `Скан {дата} {время}`), `default_filter` (`white`), `pdf_page_size` (`a4` | `fit`), `jpeg_quality` (80).

### Алгоритмы ядра

- **Поиск листа:** уменьшить до ~640 px по длинной стороне → оттенки серого → размытие → Canny → морфологическое закрытие → контуры → `approxPolyDP` → самый большой выпуклый четырёхугольник площадью > 20 % кадра. Если нет — запасной путь по границам из адаптивного порога. Не нашли — рамка по краям фото.
- **Живой контур (S02):** тот же детектор на кадрах ImageAnalysis не чаще ~10 раз в секунду, сглаживание точек между кадрами, чтобы рамка не дрожала.
- **Перспектива:** порядок углов (лево-верх по часовой), размер выходной страницы по средним длинам сторон, `warpPerspective` с `INTER_CUBIC` по полноразмерному снимку (ограничение — 4000 px по длинной стороне).
- **«Белый фон без серости» (`white`):** по каждому каналу оценить фон (уменьшить, морфологическое закрытие крупным ядром, медианный фильтр, увеличить обратно), разделить изображение на фон (выравнивание освещения и снятие теней), затем растянуть уровни так, чтобы бумага стала чисто белой (точка белого по 95-му перцентилю), с лёгким повышением контраста. Цвет печатей и подписей сохраняется.
- **`lighten`** — то же деление на фон без жёсткой точки белого. **`gray`** — `white` в оттенках серого. **`bw`** — адаптивный порог (Sauvola) после выравнивания фона.
- **«По горизонту»:** коррекция перспективы выпрямляет лист; для фото без рамки (`quad = null`) — опционально автоповорот по доминирующему углу строк (could).

## Что будет кусаться

- **Ориентация:** EXIF у камеры и галереи, поворот телефона во время съёмки, поворот на 90° как отдельное поле, а не новый файл.
- **Память:** 12–50 Мп снимки. Не держать несколько полноразмерных `Bitmap` одновременно; превью и миниатюры — уменьшенные; обработка страниц серии последовательно.
- **Смерть процесса посреди серии:** каждый снимок пишется на диск и в базу сразу (документ `is_draft`), после перезапуска черновик восстанавливается, а не теряется.
- **Согласованность файлов и базы:** сначала транзакция, потом удаление файлов; уборка «осиротевших» файлов при запуске.
- **Неверная рамка:** самопересекающийся или вогнутый четырёхугольник от пользователя — подсвечивать и не давать подтвердить.
- **Размер PDF:** JPEG 80 % и ограничение 300 dpi для A4 (около 2480×3508); проверить на документе из 50 страниц.
- **Размер APK:** OpenCV — основная часть веса; оставить только нужные ABI, включить R8 и сжатие ресурсов.
- **Хранилище:** scoped storage на API 29+, разные пути сохранения в «Загрузки» для 26–28.
- **Качество фильтра** — главный риск продукта: нужен набор из 15–20 реальных тестовых фото (чеки, акты, бланки при плохом свете) и сравнение «до/после» на каждом изменении.

## Порядок сборки

1. **Вертикальный срез** (доказывает стек и главный риск — фильтр):
   S01 простой список → S02 съёмка одной страницы (без живого контура) → S03 автообрезка + ручные углы → S04 только фильтр `white` → S05 минимальный → S07 PDF и «Поделиться».
   Таблицы: `documents`, `pages`. Функции: `createDraft`, `addFromCapture`, `EdgeDetector.detect`, `Processor.render`, `PdfExporter.export`, `Sharer.share`.
2. **Обязательные функции:** живой контур в камере, режим нескольких страниц, импорт из галереи, поворот, фильтры original / gray / bw, добавить и удалить страницу, черновики и уборка, проверка «нет сетевых разрешений».
   Экраны: S02, S03, S04, S05.
3. **Желательные:** перестановка страниц, переименование, шаблон имени (S08), переобрезка и смена фильтра после сохранения (S06), «применить ко всем», размер страницы, экспорт JPG, сохранение в «Загрузки», вспышка.
   Потом «можно потом»: поиск, папки, мультивыбор, качество PDF, OCR, пароль на PDF.
4. **Исправления из replica-entrepreneur** — после того как этап прочитает отзывы.
