# Recon-карта: CamScanner (Android)

Срез: ядро сканирования — камера или галерея → обрезка по краям → улучшение (белый фон) → многостраничный PDF → поделиться. Всё офлайн, без аккаунта.
Для кого: сам пользователь и коллеги (рабочие документы, сканы для авансовых отчётов). Без рекламы, подписок и регистрации.
Дата: 2026-10-23

## Основной цикл

Сфотографировать бумагу и через несколько касаний получить ровный, чистый PDF, которым можно сразу поделиться.

## Экраны

| ID | экран | как попасть | назначение | ключевые компоненты | состояния |
| --- | --- | --- | --- | --- | --- |
| S01 | Документы (главный) | запуск приложения | список всех сканов, вход в съёмку | список документов с миниатюрой, датой и числом страниц; FAB «камера»; кнопка импорта из галереи; меню (выбрать, сортировка); поиск по имени | пусто, заполнено, режим выбора, длинное имя |
| S02 | Камера | FAB на S01 или «добавить страницу» на S05 | съёмка страниц | превью камеры; контур найденного листа; затвор; переключатель «одна / несколько страниц»; вспышка; миниатюра последнего снимка со счётчиком; импорт из галереи | нет разрешения на камеру, лист не найден, лист найден, серия (счётчик N) |
| S03 | Обрезка | после снимка или импорта | поправить границы листа | фото с затемнением вне рамки; 4 угловых маркера (+ маркеры на сторонах — догадка); «вся страница»; «авто»; поворот на 90°; «далее» | авто-рамка найдена, не найдена (рамка по краям фото), неверный четырёхугольник (самопересечение) |
| S04 | Улучшение / фильтр | «далее» на S03 | выбрать вид страницы | крупное превью; лента фильтров: оригинал, авто, осветлить, оттенки серого, ч/б; «применить ко всем»; готово | обработка идёт, готово |
| S05 | Документ | тап по документу на S01 или после S04 | страницы документа, правка, экспорт | сетка страниц; перетаскивание для порядка; добавить страницу; удалить; переименовать; поделиться | 1 страница, много страниц, режим перестановки |
| S06 | Страница | тап по странице на S05 | работа с одной страницей | просмотр с зумом; переобрезать (→S03); сменить фильтр (→S04); повернуть; удалить | — |
| S07 | Экспорт / поделиться | «поделиться» на S05 или мультивыбор на S01 | отдать результат | формат (PDF / JPG); размер страницы (A4, по фото); качество/размер файла; системное меню «Поделиться»; сохранить в «Загрузки» | генерация PDF, ошибка записи, очень большой файл |
| S08 | Настройки | меню на S01 | умолчания | шаблон имени файла; фильтр по умолчанию; размер страницы PDF; качество | — |

## Потоки

```
F01 Отсканировать одну страницу и отправить PDF
    S01 -> S02 -> S03 -> S04 -> S05 -> S07 -> системное «Поделиться»
    касаний на счастливом пути: 6 (камера, затвор, далее, готово, поделиться, выбор приложения)
    edge: нет разрешения на камеру; лист не найден; тёмное фото; поворот телефона; нехватка места

F02 Многостраничный документ
    S01 -> S02 (режим «несколько», N снимков) -> S03 (по каждой) -> S04 (применить ко всем) -> S05 -> S07
    касаний: 4 + N затворов + N подтверждений обрезки
    edge: выход посреди серии (что с уже снятыми); 50+ страниц (память); одна страница снята криво

F03 Импорт фото из галереи
    S01 -> системный выбор фото (несколько) -> S03 -> S04 -> S05
    edge: HEIC; огромное разрешение; фото без листа (скриншот); EXIF-поворот

F04 Дополнить или поправить существующий документ
    S01 -> S05 -> «добавить» -> S02 ... / S06 -> переобрезать / сменить фильтр / повернуть
    edge: переобрезка должна идти от оригинала, а не от уже обрезанного файла

F05 Упорядочить
    S01 -> выбрать -> переименовать / удалить / поделиться несколькими
    edge: удаление без возможности отмены; одинаковые имена
```

## Модель данных (выведена)

```
Document  id, title, created_at, updated_at, page_count (вычисляемое), folder_id (необяз.)
          evidence: S01 список с именами и датами; шаблон имени в настройках (ист. 4)
          confidence: high

Page      id, document_id, position, original_path, crop_quad (4 точки в координатах оригинала),
          rotation (0/90/180/270), filter (original|auto|lighten|gray|bw), processed_path, width, height
          evidence: S03 правка рамки; S06 «переобрезать» и «сменить фильтр» работают после сохранения,
          значит оригинал и параметры хранятся отдельно от результата
          confidence: high для полей, medium для хранения оригинала

Folder    id, name, created_at
          evidence: главный экран с папками (ист. 4)
          confidence: medium (в нашем срезе — could)

Settings  name_template, default_filter, pdf_page_size, jpeg_quality
          evidence: ист. 4 (шаблон имени), S07
          confidence: medium
```

Связи: Folder 1-n Document, Document 1-n Page (упорядочены по position). Пользователя и аккаунта нет — всё локально.

## Вне рамок (нельзя или не нужно клонировать)

- Облачная синхронизация, аккаунт, веб-версия, совместная работа — это их сервис и инфраструктура; противоречит «офлайн».
- Факс в 30+ стран и внутренняя валюта C-Points — партнёрские сделки и платёжная система.
- Подписка, реклама, водяной знак «Scanned by…» — не нужны приложению «для себя».
- Загрузка в Box, Google Drive, Dropbox и т. д. — заменяется системным «Поделиться».
- Их логотип, иконки, названия режимов, тексты интерфейса и фирменный зелёный цвет — пишем своё.
- OCR, экспорт в Word, подпись, водяной знак — за рамками выбранного среза (оставлены как could / на потом).

## Размер

Экранов 8, потоков 5, сущностей 4. Трудные места: поиск краёв листа в реальном времени и на фото; коррекция перспективы без потери резкости; фильтр «белый фон без серости» с удалением теней; память при сериях больших фото; размер PDF. Размер: **M** (несколько недель по вечерам).
